# 🤖 Curiosidades de Tecnologia: a história do mascote do Android

Página em HTML e CSS com um artigo sobre a origem do mascote do Android, desde a primeira versão criada por Dan Morrill até o Bugdroid desenhado por Irina Blok.

Atividade feita em 2022 durante o **Curso de HTML5 e CSS3 do [Curso em Vídeo](https://www.cursoemvideo.com/)** (Gustavo Guanabara), um dos meus primeiros projetos com desenvolvimento web.

## 🧠 O que pratiquei

- Estrutura semântica com `header`, `nav`, `main` e `article`
- Imagens responsivas com `<picture>` e `<source media>` (versão menor para telas pequenas)
- Fonte personalizada com `@font-face`
- Estilização com gradientes, sombras e bordas arredondadas
- Favicon e links externos
